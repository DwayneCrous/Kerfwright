# The application: welcome page, projects and workspaces

`cargo run --release -p kw-app` starts **Kerfwright**, the one program that ties the engines of Phases 1–5 together, laid out like Fusion 360: a light theme, an application bar, a ribbon with tabs and grouped icon buttons, a browser tree, a timeline and a view cube. `scripts/app_acceptance.sh` runs the tests and writes a screenshot of every screen to `target/app/`.

## Welcome page
New design (name + folder, saved at once as `<name>.kwf`), Open project (native dialog), Open the demo part, and the ten most recent projects (kept in `~/.config/kerfwright/recent.json`; missing files are marked with a "Forget" button). `kerfwright FILE.kwf`, `--demo` and `--workspace NAME` skip it.

## Project and frame
A project is a `.kwf` file: the feature document of Phase 4 plus the Phase 5 data as extra entries (`cam.cbor`, `fea.cbor`, `board.cbor`, through `kw-store`). **Application bar:** home (back to the welcome page), File, Undo / Redo, Save (Ctrl+S, Ctrl+Z, Ctrl+Y), the project name with `*` while unsaved; closing, opening another project or quitting asks before discarding changes. **Ribbon:** the workspace menu at the left (DESIGN / MANUFACTURE / SIMULATION / ELECTRONICS / RENDER) and the tabs and tool groups of that workspace.

## Design (Sketch and Model as one workspace)
* **Create Sketch** → the view shows the three origin planes (hover highlights, planar faces highlight too) → click a **plane or a planar face of the body** (curved faces are refused with a message) → the view becomes the flat sketch canvas with the ribbon's **SKETCH** tab (Line, Rectangle, Circle, Arc, Spline, Point; Trim, Extend, Offset; Dimension and the 13 constraints; Finish Sketch / Discard) and a sketch palette at the right with the solver state. When sketching on a face, the body's edges in that plane are drawn as faint reference lines and frame the canvas.
* **Snapping and inference** (as in Fusion 360; the **Snaps** list in the sketch palette and in the ribbon's SNAPS menu switches each kind off): the cursor snaps, in this order, to an existing **point** (square), the **origin** (circle with cross), the **midpoint** of a line (triangle), the **intersection** of two curves (cross), a point **on a curve** (ring), dashed **inference lines**, and finally the **grid** (adaptive spacing). Inference lines are horizontal / vertical and multiples of the **angle step** (15° by default, 5°–90° selectable) from the start of the line being drawn, **parallel / perpendicular** to existing lines, and horizontal / vertical **alignments** with points the cursor has rested on for 0.3 s (marked with a small +); where two lines cross the cursor snaps to the crossing. A label shows length and angle while drawing and the name of the snap. Completing a snap adds the matching **constraint**: midpoint, point-on-curve on both curves at an intersection, a fixed point at the origin, horizontal / vertical / parallel / perpendicular for the line that was inferred (angle, alignment and grid snaps only place geometry). Hold **Alt** to ignore all snaps for one click. Not done: snapping while dragging existing geometry, typing an exact length / angle.
* **Finish Sketch** → the **Extrude dialog opens at once** with that sketch, defaulting to *Join* when the sketch lies on a body (*New Body* otherwise). The model shows a **live preview** of the result (cut, join …) as you change distance, direction, symmetric or operation; an arrow in the view drags the distance; OK commits, Cancel discards, a failing preview is shown in red and blocks OK.
* **Tools** (ribbon SOLID tab): Extrude, Revolve, Hole (click a face to place it), Rectangular and Circular pattern, Mirror, Fillet, Chamfer (click edges, Shift adds), Shell (click the faces to remove), Combine, Change Parameters (named values usable in any expression), Origin Planes. Each is the same kind of dialog and edits an existing feature too.
* **Browser** (left): Document Settings, Origin (planes with eye toggles), Sketches (eye toggle shows or hides the sketch in 3-D), Bodies, Features. Click selects, double-click edits, right-click offers Edit / Suppress / Roll back here / Delete.
* **Timeline** (bottom): a chip per feature (red when it fails, grey when suppressed), drag to reorder (refused with the engine's message when a feature would come before something it needs), a rollback marker (drag it, or use the |< < > >| buttons), the same context menu. While rolled back, adding features is refused until the timeline is rolled forward.
* **View**: the view cube (click a face to turn the camera there, animated), orbit (drag), pan (right/middle drag), zoom (wheel), hover and selection highlights, and a navigation bar (Home, Fit, shaded / wireframe, edges, planes).

## Other workspaces (same frame, own panels)
**MANUFACTURE** (CAM): Pocket, Adaptive Clearing, 2D Contour, 3D Finish and Simulate in the ribbon; settings, operations and G-code post in the left panel (five dialects). **SIMULATION** (FEA): Solve and result colouring; supports and loads on faces picked in the view. **ELECTRONICS** (ECAD): sample board, Place, Route All, Check, Pour, fabrication files, STEP; layers and violations in the panel. **RENDER**: Realtime / Path Trace, Denoise, Save PNG.

## What is verified, and what is not
* `crates/kw-app/tests/shell.rs` (26 tests): the shell tests of the first version, plus the Fusion flows: sketch on a plane → straight into a previewed Extrude → OK (volume 3000); pick a planar face → sketch on it → Cut with the dialog → volume 3000 − π·3²·2; a curved face is refused; Escape / Discard leave nothing behind; timeline reorder accepted and refused, rollback and roll-forward, suppress, edit-in-place of an extrude and of its sketch (the downstream volume follows), delete refused when something depends on a feature, adding refused while rolled back; chamfer, shell, hole and rectangular pattern against closed-form volumes; revolve against π(R²−r²)h; view-cube mapping and camera interpolation; the plane under the pointer; a triangle drawn with the origin, horizontal and 135° snaps extruding to the exact volume. Snap logic itself: `crates/kw-sketch/tests/snaps.rs` (13 tests: midpoint, intersection, origin, polar angles, parallel / perpendicular, alignment, grid, priorities, random clicks never conflict) and `crates/kw-sketcher/tests/ui.rs` (dwell-to-acquire, Alt, every marker draws).
* Screenshots come from the real application through eframe, so the GPU path into egui, the light theme and the layout are checked on every screen listed in `scripts/app_acceptance.sh`.
* **Not tested here:** real mouse and keyboard interaction in a window (clicking ribbon buttons, dragging chips and the extrude arrow, orbiting) and the native file dialogs. The logic behind every click is tested through the same code paths (`handle_clicks`, actions, dialogs), but the pointer handling itself needs a hand test.

## Limits
* Extrude uses **all** closed loops of the sketch (outer loop plus holes); a single region cannot be chosen, and there is no "to face" or "through all" extent. Revolve's axis is the sketch X or Y axis. Mirror and circular pattern use world planes and axes. Fillet / chamfer / shell reference faces by name; a feature added while the model is rolled back is refused rather than inserted at the marker.
* SURFACE, MESH, SHEET METAL tabs, Measure, construct planes and sketch constraints beyond the 13 listed are not in the UI (the engine has sheet metal and SubD).
* Sketching is on the flat 2-D canvas, not in the 3-D view. The model is evaluated on the UI thread (a very heavy model pauses the window); CAM, FEA, routing, stock simulation and denoising run on background threads.
* CAM works on rectangles (typed or the model's bounding box); FEA meshes the first body's faceted tessellation and stores supports and loads by face index (stale if the geometry changes shape); ECAD offers generated sample boards only; Render uses its own GPU device and a fixed 960×600 image.
